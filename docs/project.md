# Описание проекта

## Название

Развитие дополнительного профессионального образования (ДПО)
Московского политехнического университета

## Цель

Повысить узнаваемость и привлекательность программ ДПО Московского
политехнического университета с помощью современных инструментов
digital-продвижения.

## Задачи нашей команды

- Изучить форматы короткого видео (Reels, YouTube Shorts)
- Выбрать курсы ДПО для продвижения
- Написать сценарии рекламных роликов
- Снять и смонтировать видеоматериалы
- Передать готовые материалы куратору на согласование

## Технологии

- CapCut / DaVinci Resolve
- Git / GitHub
- Hugo (статический сайт)
- Markdown

## Ожидаемый результат

Серия коротких рекламных видеороликов о курсах ДПО Московского
политехнического университета, технический сайт практики, отчёт по практике.
