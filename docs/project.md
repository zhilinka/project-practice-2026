# Описание проекта

## Название
Python: How To Create a Telegram Bot Using Python

## Цель
Изучить технологию создания Telegram-ботов на Python и разработать
работающего бота с практическим функционалом.

## Задачи
- Изучить Telegram Bot API и библиотеку python-telegram-bot
- Разработать Telegram-бота с набором команд
- Написать техническое руководство по созданию бота
- Задокументировать проект в репозитории и на сайте
- Подготовить видео-презентацию проекта

## Технологии
- Python 3.x
- Библиотека python-telegram-bot
- Git / GitHub
- Markdown
- HTML / CSS (статический сайт)

## Ожидаемый результат
Работающий Telegram-бот, техническое руководство в формате Markdown,
статический сайт с описанием проекта, отчёт по практике.
