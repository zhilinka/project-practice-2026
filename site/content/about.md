## О проекте

Проект выполняется в рамках проектной (учебной) практики 2025–2026 совместно
с Московским политехническим университетом.

## Название проекта

«Развитие дополнительного профессионального образования (ДПО) Московского политеха»

## Цель

Повысить узнаваемость и привлекательность программ ДПО Московского политехнического
университета с помощью современных инструментов digital-продвижения.

## Задачи проекта (все команды)

- Изучить целевую аудиторию программ ДПО и её потребности
- Разработать рекламные текстовые материалы о курсах
- Создать короткие видеоролики, продвигающие курсы ДПО
- Разработать Telegram-бот для информирования о программах ДПО
- Задокументировать результаты и оформить сайт практики

## Задачи нашей команды (короткие ролики)

- Изучить форматы короткого видео (Reels, Shorts) и требования к рекламному контенту
- Выбрать курсы ДПО для продвижения
- Написать сценарии роликов
- Снять и смонтировать видеоматериалы
- Опубликовать готовые ролики

## Технологии и инструменты

- Видеоредактор (CapCut / DaVinci Resolve / другой)
- Git / GitHub
- Hugo (статический сайт)
- Markdown
